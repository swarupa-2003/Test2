# 💰 Smart Expense Tracker

## 📱 About the Project

**Smart Expense Tracker** is an Android application designed to help users manage and track their daily expenses conveniently. The application provides a simple and user-friendly interface for monitoring spending and organizing financial information.

This project is developed as part of the **Mobile Application Development** coursework using **Android Studio** and **Kotlin**.

---

## ✨ Features

- 💰 Track daily expenses
- 📊 Monitor spending activities
- 📝 Simple and user-friendly interface
- 📱 Android mobile application
- ⚡ Built using Kotlin
- 🎨 Modern Android UI design

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/your-username/SmartExpenseTracker.git
```

2. Open **Android Studio**.

3. Select **Open** and choose the project folder.

4. Allow **Gradle Sync** to complete.

5. Connect an Android device or start an emulator.

6. Click the **Run ▶️** button.
